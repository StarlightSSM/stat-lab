# 연구통계 실험실

응용확률및통계 · 행동연구방법론 · 구조방정식(AMOS) · SPSS · R · MIS 개념 48개를 슬라이더로 직접 조작해 보는 시뮬레이션 학습 사이트.

두 가지 화면이 있습니다.
- **3D 책** (`http://localhost:8800`): 책상 위의 책을 펼쳐 책장을 넘기며 읽습니다. 쪽마다 실험이 그대로 살아 있고, 일부 실험은 종이 위로 솟아오르는 입체 그림(끌어서 회전)이 있습니다.
- **평면 사이트** (`http://localhost:8800/classic`): 같은 내용을 일반 웹페이지로 봅니다.

## 실행

- **더블클릭**: `start.bat` → 브라우저가 `http://localhost:8800` 으로 열립니다.
- **터미널**: `node serve.js` (포트 변경: `PORT=9000 node serve.js`)
- 종료: 서버 창에서 `Ctrl+C`

Node.js만 있으면 되고, 설치할 패키지는 없습니다. 차트 라이브러리(d3), 3D 라이브러리(three.js 0.160)와 글꼴은 CDN에서 받으므로 인터넷 연결이 필요합니다.

### 3D 책 조작
- 책장 넘기기: 쪽 아래 바깥 모서리 클릭, ← → 키, 아래 막대의 화살표, 터치 화면은 좌우로 밀기
- 아래 막대: 차례 · 펼침면/한 쪽 보기 · 둘러보기(책상 회전) · 밤 조명 · 책장 소리 · 평면 보기
- 입체 그림: 끌어서 회전, 두 번 눌러 처음 각도로

## 구조

| 경로 | 내용 |
|---|---|
| `book.html` | 3D 책 화면 뼈대 |
| `js/book/` | 3D 책 엔진 (책상·책 모델, 책장 넘김, 카메라, 쪽 구성, 쪽 스냅샷) |
| `js/fig/*.js` | 입체 그림 (`tools/README-fig.md` 참고) |
| `css/lab.css`, `css/book.css` | 공용 스타일, 3D 책 스타일 |
| `index.html` | 평면 사이트 뼈대 |
| `js/stats.js` | 통계 엔진 (분포, 검정, 회귀, 행렬, 신뢰도) |
| `js/core.js` | 라우터, 조절판, 차트(Plot), 경로도(Diagram) |
| `js/m/*.js` | 모듈 1개 = 파일 1개 |
| `js/resources.js` | 공개 강의자료 73건 (2026-11-08 접속 확인) |
| `serve.js` | 로컬 서버 |
| `tools/` | 빌드·미리보기·점검 스크립트 |

## 모듈 추가

1. `js/m/<id>.js` 에 `Lab.add({...})` 작성 (`js/m/dist-normal.js` 참고)
2. `node tools/build.js` → `index.html`, `book.html` 에 스크립트 태그 반영 (입체 그림도 같은 방식: `js/fig/<id>.js`)
3. `node tools/checkall.js` 후 `.preview/full.html` 을 열어 모든 모듈 오류 점검
